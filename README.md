# Rachel Bus ETA

iPhone 用嘅輕量巴士到站頁，跟住 Kindle 畫面嗰種大時鐘、大路線號碼排版。一次睇 **九巴 299X、99** 同 **城巴 580** 喺你揀嘅車站、每個方向最多三班車。

冇後端、冇 API key。資料直接由瀏覽器讀運輸署公開接口。

## 點用

1. 用 iPhone **Safari** 打開頁面（加入主畫面之前，唔好用 App 入面嘅內置瀏覽器）。
2. 第一屏預設係 **輋下**（如果車站清單有呢個名）。之後會記住你最後揀嘅站。
3. 撳車站名旁邊嘅「更改」。車站由沙田一端排到西貢一端，亦可以用中文搜尋。
4. 每個方向最多顯示三個到站時間，例如「即將」「9 分鐘」。大約每兩分鐘自動更新。喺頁面最頂拉下，或者撳最底「更新」，可以即刻再攞一次。
5. 直播班次需要網絡。離線只可以開到頁面殼，睇唔到新班次。

### 加入主畫面

1. Safari 打開頁面後，撳底部分享按鈕。
2. 揀「加入主畫面」，再撳「加入」。
3. 之後由主畫面圖示打開，會以全螢幕顯示，頂部係香港日期同時間。

## 開啟 GitHub Pages

合併到 `main` 之後，由 repo 擁有人自己開 Pages（呢個專案唔會代為開啟）：

1. 打開 GitHub repo → **Settings** → **Pages**。
2. **Build and deployment** 選 **Deploy from a branch**。
3. Branch 選 **main**，資料夾選 **/ (root)**，然後 Save。
4. 等幾分鐘，頁面會喺 `https://<用戶名>.github.io/Rachel-Bus-ETA/` 出現。
5. 用 Safari 打開上面個網址，再按上一節加入主畫面。

頁面係靜態檔，唔使 build。

## 車站點樣合併

九巴同城巴嘅車站編號唔相通，來回兩邊往往亦係兩個編號。揀站時會：

- 將中文站名相同嘅站合成一個選項（去掉九巴站號如 `(SK302)`、城巴路名如「, 西沙路」，以及「總站」）。
- 約 40 米內、其實係同一路邊但官方名唔同嘅站亦會合併。例如城巴往沙田市中心喺輋下對面叫做「官坑」，所以揀「輋下」會一齊顯示 580 兩個方向。
- 距離再遠嘅村（例如泥涌同西澳）維持分開。

清單跟官方路線站序，由沙田排到西貢。主線係 299X 往西貢嘅站序。99 往西貢，同 580 由沙田市中心開往西沙灣，如果有主線冇停嘅站，會跟住自己嗰段路線，排喺分岔或者接返主線嘅位置，唔會插亂主線。

某條路線唔經呢個站，就唔會顯示嗰條路線。

## 資料來源

到站時間同車站名單來自政府公開數據，大約每分鐘更新；本頁約每兩分鐘擷取一次。

- 九巴（299X、99）：<https://data.gov.hk/tc-data/dataset/hk-td-tis_21-etakmb>
  - 介面根路徑：`https://data.etabus.gov.hk/v1/transport/kmb/`
- 城巴（580，公司代碼 CTB）：<https://data.gov.hk/tc-data/dataset/ctb-eta-transport-realtime-eta>
  - 介面根路徑：`https://rt.data.gov.hk/v2/transport/citybus/`

瀏覽器只會將你最後揀嘅車站，同車站名稱快取，存在這部手機嘅 `localStorage`。冇帳號、冇密碼、冇私人日曆連結。
